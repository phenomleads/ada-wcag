# ADA WCAG Accessibility Checker

A TypeScript CLI tool that fetches a URL or local HTML file and audits it against WCAG 2.1 Level AA success criteria (image alt text, form labels, heading hierarchy, link text, color contrast), producing a structured JSON report.

> Full project documentation (installation, usage, lesson-to-file map) is completed in a later task. This section currently covers Lesson 5 evidence only.

## Lesson 5: Powers — Power Builder

**Power Builder** was installed from the Kiro powers registry via the Powers panel. It packages the Agent Plugins specification and skills for creating and validating Kiro Powers.

It is used during development to scaffold and check the Bonus Lesson 2 power (`power/` — `ada-wcag`), by triggering it with a keyword in chat (e.g. "build a power", "create plugin") and following its guidance for the `plugin.json` manifest and `SKILL.md` structure.

Power Builder is the only power claimed for Lesson 5. The `ada-wcag` power built with its help is a separate submission for Bonus Lesson 2 and is not claimed for Lesson 5.
