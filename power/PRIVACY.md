# Privacy Policy — ada-wcag Kiro Power

This Power is a skills-only guidance package. It contains no MCP server, no scripts, and no code that executes network requests on its own.

## Data collection

This Power does not collect, store, transmit, or process any personal data, telemetry, or usage analytics. All content (`SKILL.md` and its references) is static markdown and JSON consumed entirely within your local Kiro session.

## Third-party services

This Power does not call any third-party APIs or services. It does not depend on or bundle any MCP server.

## Changes

If this policy changes, the update will be committed to this repository with a visible revision in the commit history.

## Contact

For privacy-related questions, open an issue on this repository or see the contact in [README.md](./README.md).
